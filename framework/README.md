# jmz — إطار فتح قفل التنشيط (كل الإصدارات)

أداة واحدة تعرف كل الأجهزة والإصدارات، وتقول لك بالضبط:
**ينفتح / بشرط / لا** — وأي طريقة، وهل تحتاج إنترنت أو هاردوير.

## التشغيل

```bash
python -m jmz matrix            # مصفوفة الدعم كلها
python -m jmz plan --chip A15 --ios 26.1 --model "iPhone 13"
python -m jmz methods           # الطرق المسجلة
python -m jmz doctor            # فحص البيئة
```

ويندوز: `run.bat` — لينكس/ماك: `./run.sh`

## مثال

```
  الجهاز: iPhone 13   |   iOS 26.1
  الحكم   : ⚠️ بشرط
  الطريقة : session
  بدون إنترنت: لا
```

## الطرق الحالية

| الطريقة | المعالجات | إنترنت | هاردوير |
|---|---|---|---|
| `checkm8` | A7–A11 | ❌ لا | لا |
| `usbliter8` | A12/A13 | ❌ لا | RP2350 |
| `session` | A12–A17 | ✅ نعم | لا |

## الإضافة المستقبلية

كل ثغرة جديدة تُضاف كملف واحد في `jmz/methods/` — اقرأ `PLUGINS.md`.
